# 电话语音指令服务 (VoiceCTL)

## 项目简介

电话语音指令服务是一个基于Android平台的语音交互应用，通过WebSocket与服务器进行实时通信，支持音频录制、播放和Opus编解码，实现语音指令的发送和接收。

## 功能特点

- **WebSocket通信**：与服务器建立实时连接，支持双向数据传输
- **音频录制**：使用Android AudioRecord API录制音频，支持16kHz采样率、单声道、16位PCM格式
- **Opus编解码**：将PCM音频编码为Opus格式发送，接收并解码Opus音频播放
- **音频播放**：使用Android AudioTrack API播放解码后的PCM音频
- **设备配置**：支持设备ID、名称、MAC地址和认证令牌的配置
- **会话管理**：支持会话状态管理，包括连接状态、录音状态和会话情绪
- **消息交互**：支持文本消息和语音消息的发送和接收
- **可视化界面**：基于Jetpack Compose的现代化UI设计

## 核心组件

### 1. AudioPlayer

音频播放组件，负责解码和播放Opus音频数据。

- 支持48000Hz采样率的Opus解码
- 自动处理解码失败和重新初始化
- 支持音频流播放模式

### 2. AudioRecorder

音频录制组件，负责录制PCM音频并编码为Opus格式。

- 支持16000Hz采样率、单声道、16位PCM录制
- 自动将PCM数据编码为Opus格式
- 支持录音状态回调
- 支持音频可视化数据生成

### 3. WebSocketHandler

WebSocket通信管理组件，处理与服务器的连接和消息收发。

- 支持设备配置管理
- 处理连接状态变化
- 支持文本消息和二进制消息的收发
- 处理会话状态和情绪变化

### 4. OpusCodec

Opus音频编解码组件，负责PCM和Opus格式之间的转换。

- 支持16000Hz和48000Hz采样率
- 支持单声道音频编解码
- 高效的Opus编码压缩

## 界面说明

### 1. 设备配置面板

- 设备MAC地址：设备的唯一标识符
- 设备名称：设备的显示名称
- 客户端ID：客户端的唯一标识符
- 认证令牌：连接服务器所需的认证信息

### 2. 连接信息面板

- OTA服务器地址：用于获取WebSocket服务器地址
- 服务器地址：实际连接的WebSocket服务器地址
- 连接状态：显示OTA和WebSocket连接状态

### 3. 消息和语音面板

- 文本消息：支持文本消息的发送和接收
- 语音消息：支持语音录制和播放
- 会话状态：显示当前会话状态和情绪
- 对话记录：显示历史对话消息
- 日志信息：显示系统日志

### 4. MCP工具管理面板

- 支持MCP工具的管理和扩展
- 显示已连接的工具数量

## 使用方法

1. **配置设备信息**：
   - 点击设备配置面板的"编辑"按钮
   - 填写设备MAC地址、名称、客户端ID和认证令牌
   - 点击"确定"保存配置

2. **连接服务器**：
   - 在连接信息面板中填写OTA服务器地址
   - 点击"连接"按钮
   - 应用会自动连接到OTA服务器获取WebSocket地址，然后连接到WebSocket服务器

3. **发送消息**：
   - 切换到"文本消息"标签页
   - 输入文本消息
   - 点击"发送"按钮

4. **录制语音**：
   - 切换到"语音消息"标签页
   - 点击"开始录音"按钮
   - 录制完成后点击"停止录音"
   - 录音数据会自动编码为Opus格式发送到服务器

## 权限要求

- `INTERNET`：网络访问权限
- `ACCESS_NETWORK_STATE`：获取网络状态权限
- `ACCESS_WIFI_STATE`：获取WiFi状态权限
- `RECORD_AUDIO`：录音权限
- `MODIFY_AUDIO_SETTINGS`：修改音频设置权限
- `FOREGROUND_SERVICE`：前台服务权限

## 消息格式

### WebSocket消息类型

- **hello**：握手消息，用于建立连接
- **listen**：监听状态消息，用于控制录音状态
- **tts**：文本转语音消息，用于播放语音
- **audio**：音频控制消息
- **stt**：语音转文本消息，用于返回语音识别结果
- **llm**：大模型回复消息
- **mcp**：MCP工具消息

## 注意事项

1. 确保设备已连接到网络
2. 确保已授予录音权限
3. 确保OTA服务器地址正确
4. 确保设备配置信息完整
5. 首次运行需允许应用获取录音权限

## 常见问题

### Q: 无法连接到服务器？
A: 请检查OTA服务器地址是否正确，网络连接是否正常，设备配置是否完整。

### Q: 录音没有声音？
A: 请检查是否已授予录音权限，麦克风是否正常工作。

### Q: 播放没有声音？
A: 请检查设备音量是否正常，扬声器是否工作正常。

### Q: 连接经常断开？
A: 请检查网络稳定性，服务器是否正常运行。
